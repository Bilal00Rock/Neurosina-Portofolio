# نوروسینا — ماژول نمونه‌کار پروژه‌ها

این Prototype یک نمونه از بخشی است که می‌تواند به سایت NeuroSina اضافه شود.

یک تجربهٔ RTL فارسی برای معرفی پروژه‌های نرم‌افزاری و هوش مصنوعی نوروسینا است؛ با دادهٔ ایستا، بدون بک‌اند سنگین، و قابل ادغام در وب‌سایت فعلی شرکت.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
```

خروجی production در پوشه `dist/` ساخته می‌شود (کپی دارایی‌های استاتیک شامل تصاویر پروژه‌ها، CSS و JS). استقرار اصلی این ماژول روی Vercel و SSR است.

## ویرایش اطلاعات پروژه‌ها

منبع حقیقت پروژه‌ها این فایل است:

`src/data/projects.ts`

برای هر پروژه می‌توانید تغییر دهید:

- نام، دسته، توضیح کوتاه
- نقش و فناوری‌ها
- متن مطالعه موردی (چالش، راه‌حل، تجربه محصول)
- مسیر داده / هوش مصنوعی (فقط اگر تأیید شده باشد)
- بخش‌های وب، موبایل و داشبورد (اگر اطلاعاتی وجود ندارد، آن فیلد را خالی بگذارید تا نمایش داده نشود)
- فهرست تصاویر

توانمندی‌ها، رشته‌های تیم و دیوار فناوری در این فایل است:

`src/data/site.ts`

**قانون محتوا:** دقت، اندازه دیتاست، تعداد کاربر، دقت مدل، زیرساخت ابری و آمار عملکرد را وارد نکنید مگر اینکه تأیید شده باشند.

## مسیرها و ادغام در سایت فعلی

این ماژول مستقل است و دو مسیر ادغام دارد:

### A — مسیر مستقل

`/portfolio`

نسخه کامل: مقدمه، توانمندی‌ها، پروژه‌ها، تیم، فناوری.

### B — بخش قابل جاسازی

`/projects`

فقط فهرست پروژه‌ها، مناسب برای قرارگیری داخل سایت فعلی.

مطالعه موردی هر پروژه:

`/projects/:slug`

نمونه‌ها:

- `/projects/pineu`
- `/projects/scratch-catch`
- `/projects/image-enhancement`
- `/projects/crm`

برای ادغام در وب‌سایت موجود:

1. همین فرانت را به‌صورت یک route جدا نگه دارید؛ یا
2. کامپوننت‌های `src/pages/Portfolio.tsx` و `src/pages/ProjectDetails.tsx` را به همراه `src/data` و `src/components` به پروژه فعلی منتقل کنید.

وابستگی‌های اصلی: React، TypeScript، Tailwind CSS، Framer Motion، Lucide React. بک‌اند اجباری نیست.
