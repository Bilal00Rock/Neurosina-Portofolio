# نمونه‌کار پروژه‌ها

وب‌سایت مستقل فارسی و راست‌به‌چپ برای معرفی پروژه‌های نرم‌افزاری، هوش مصنوعی و محصولات دیجیتال. نام نمایشی فعلی «استودیو ما / Our Studio» یک جای‌نگهدار است و هویت نهایی هنوز انتخاب نشده است.

## فناوری‌ها

- React 19 و TypeScript
- TanStack Start و TanStack Router
- Tailwind CSS 4
- Framer Motion و Lucide React
- رندر و استقرار فعلی با Nitro برای Netlify

## اجرا و بررسی

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run lint
npm run build
```

ساخت فعلی به پیکربندی Netlify در `netlify.toml` متکی است و خروجی آن در `dist/` قرار می‌گیرد. این خروجی شامل بخش سمت‌سرور Netlify نیز هست؛ آن را مانند یک وب‌سایت کاملاً ایستا در میزبان دیگری بارگذاری نکنید، مگر اینکه خروجی و مسیرهای مستقیم پروژه برای آن میزبان جداگانه آماده و آزمایش شده باشند.

## تنظیم هویت و SEO

مقادیر برند، ایمیل تماس، پیوندهای شبکه‌های اجتماعی، دامنه عمومی و پیش‌فرض‌های SEO در `src/data/site.ts` نگهداری می‌شوند. نام موقت را پس از انتخاب هویت نهایی در همان فایل عوض کنید. تا وقتی دامنه نهایی تأیید نشده، `publicUrl` خالی است؛ با واردکردن دامنه، canonical و آدرس‌های مطلق اشتراک‌گذاری در metadata ساخته می‌شوند.

تصویر اشتراک‌گذاری `public/og.jpg` و نماد عمومی مرورگر `public/favicon.svg` هستند. تصویر اجتماعی از طرح بدون نام تجاری استفاده می‌کند تا با تغییر نام نیازی به بازطراحی نداشته باشد.

## نگهداری پروژه‌ها

اطلاعات و مطالعه‌های موردی در `src/data/projects.ts` منبع اصلی محتوا هستند. برای افزودن یا ویرایش پروژه، همان آرایه را تغییر دهید و تصاویر اصلی را در پوشه‌ای زیر `public/projects/` قرار دهید. فیلدهای اختیاری پیوندهای دموی زنده، مخزن کد و وب‌سایت رسمی را پوشش می‌دهند.

- `Pineu` یک پروژه پایش سلامت مستقل است؛ تصاویر اصلی آن در `public/projects/pineu/` قرار دارند.
- `Scratch Catch` تصاویر اصلی وب، موبایل و نتیجه تشخیص را در `public/projects/scratch-catch/` دارد.
- برای `Piano` هنوز تصویر یا شرح تأییدشده‌ای در مخزن موجود نیست؛ در سایت به‌صورت جای‌نگهدار مشخص شده و پیوند وب‌سایت رسمی آن (`https://techread.nl/`) جدا از نمونه‌کار نگه داشته شده است.
- دارایی‌های بهبود تصویر و CRM در پوشه‌های هم‌نام زیر `public/projects/` نگهداری می‌شوند.

محتوای معرفی پروژه فقط باید بر پایه اطلاعات تأییدشده تکمیل شود. تصویر جای‌نگهدار Piano اسکرین‌شات محصول نیست و نباید به‌عنوان تصویر واقعی معرفی شود.

## مسیرها

- `/` و `/portfolio`: نمونه‌کار کامل
- `/projects`: فهرست فشرده پروژه‌ها، برای نمایش در یک بخش جداگانه
- `/projects/:slug`: مطالعه موردی هر پروژه

## استقرار

مخزن را به سایت Netlify متصل کنید و از تنظیمات موجود در `netlify.toml` استفاده کنید: دستور ساخت `npm run build` و پوشه انتشار `dist`. پس از بررسی build، یک deploy preview بسازید و مسیرهای `/`, `/projects` و `/projects/piano` را بررسی کنید. دامنه نهایی را در `company.publicUrl` در `src/data/site.ts` تنظیم کنید و deploy نهایی را فقط پس از تأیید مالک سایت انجام دهید.

برای گزینه‌ها و محدودیت‌های ادغام با WordPress، فایل [WORDPRESS_INTEGRATION.md](./WORDPRESS_INTEGRATION.md) را ببینید.
